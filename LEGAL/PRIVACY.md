# Informativa Privacy – Future Molding (beta)

- L'applicazione lavora in modalità offline per impostazione predefinita.
- I file CAD, le analisi e le miniature sono memorizzati localmente nel browser
  (IndexedDB / localStorage) e non vengono inviati a server esterni, salvo
  esplicita attivazione della funzione AI Cloud.
- Quando l'AI Cloud è disabilitata, ogni chiamata agli endpoint /api/ai/* viene
  rifiutata lato server.
- L'utente è responsabile della gestione dei propri file e backup.
