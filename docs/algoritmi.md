# Algoritmi chiave (Future Molding)

## Punto di commutazione (switch point)
**Formula (cm³):**  
`V_switch = (V_cavità + V_materozza) * (1 + ritiro%) - Cushion_target`

**Assunzioni:** definisci ritiro per materiale (es. PP, ABS, PC, PA-GF40).  
**Casi limite:** `Cushion=0`, spessori sottili (<1.2mm), pressa sotto-tonnellata.

## Raffreddamento (nota di principio)
